# WindowController

WindowController renders a modal dialog or a movable floating work surface. It
can operate alone, or participate in an application WindowManager.

## React usage

```tsx
import { Panel } from '@/react/components/Panel';
import { WindowController, useWindowContext } from '@/react/components/WindowController';

function WindowContent() {
  const { close } = useWindowContext();

  return <Panel closeButton onClose={() => close()} title='Account settings'>Update your profile details.</Panel>;
}

export function MyComponent() {
  return (
    <WindowController ariaLabel='Account settings'>
      <WindowContent />
    </WindowController>
  );
}
```

## Managed floating windows

Create one manager at the application boundary and install it with
`WindowManagerProvider` or `installWindowManager(...)` on `GlobalContext`.
Mount managed windows through `Portal` with the same manager instance.

```tsx
import { createWindowManager } from '@pastweb/tools';
import { Portal, WindowManagerProvider, usePortal } from '@pastweb/react';
import { WindowController } from '@/react/components/WindowController';

const windowManager = createWindowManager();

function EditorWindow() {
  const editor = usePortal();

  return (
    <>
      <button type='button' onClick={() => editor.open()}>Open editor</button>
      <Portal path='window' use={editor} manager={windowManager}>
        <WindowController manager={windowManager} mode='floating' ariaLabel='Editor'>
          <div>Editor content</div>
        </WindowController>
      </Portal>
    </>
  );
}

export function MyComponent() {
  return <WindowManagerProvider manager={windowManager}><EditorWindow /></WindowManagerProvider>;
}
```

## Configurations

```tsx
<WindowController mode='floating' ariaLabel='Inspector' width={480} height={360} resizable>
  <Inspector />
</WindowController>
```
