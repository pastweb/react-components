# Buttons

Buttons groups related actions under one accessible label. Use it when a set of
Button components belongs to the same operation or decision.

## React usage

```tsx
import { Button } from '@/react/components/Button';
import { Buttons } from '@/react/components/Buttons';

export function MyComponent() {
  return (
    <Buttons ariaLabel='Account actions'>
      <Button>Save changes</Button>
      <Button outlined>Cancel</Button>
    </Buttons>
  );
}
```
