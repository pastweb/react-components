# Style Settings

As standard the components props contains a `cls` prop which is a customised instance of the "cl" function imported
from `@pastweb/tools`. This function allow the module composition reducing the amount of css necessary to apply common style rules
as example for utility classes (is-primary, is-warning...) keeping consistancy in the whole codebase.

The `@` alias points always to the `src` project directory.
