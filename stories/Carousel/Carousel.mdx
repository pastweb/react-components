# Carousel

Carousel presents a sequence of labelled slides with previous and next
controls. Optional autoplay can be paused and resumed by the user.

## React usage

```tsx
import { Carousel, CarouselItem } from '@/react/components/Carousel';

export function MyComponent() {
  return (
    <Carousel ariaLabel='Featured articles'>
      <CarouselItem>First article</CarouselItem>
      <CarouselItem>Second article</CarouselItem>
    </Carousel>
  );
}
```

## `useCarouselContext`

`useCarouselContext(): CarouselContext` gives custom descendants access to the
nearest Carousel's live state and command methods. Call it only from a component
rendered inside `Carousel`, including content supplied to the `commands` slot.

The context provides these live values:

- `current`: the zero-based active slide index;
- `itemsCount`: the number of registered CarouselItem components;
- `isDisabled`: `true` when Carousel commands are unavailable; and
- `isPaused`: `true` while autoplay is paused for any reason.

It also provides these methods:

- `prev()` and `next()` navigate between slides;
- `toggleAutoplay()` switches the user-controlled autoplay pause state; and
- `registerItem()` registers a compatible slide implementation. Ordinary
  custom commands do not need to call it because CarouselItem registers itself.
