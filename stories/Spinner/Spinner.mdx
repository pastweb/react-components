# Spinner

Spinner displays a rotating visual indicator and exposes a polite loading status.

## React usage

```tsx
import { Spinner } from '@/react/components/Spinner';

export function MyComponent() {
  return <Spinner ariaLabel='Loading account details' />;
}
```
