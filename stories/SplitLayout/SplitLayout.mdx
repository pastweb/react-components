# SplitLayout

SplitLayout arranges resizable panels separated by pointer- and keyboard-operable
controls.

## React usage

```tsx
import { SplitLayout, SplitLayoutItem } from '@/react/components/SplitLayout';

export function MyComponent() {
  return (
    <SplitLayout ariaLabel='Workspace panels'>
      <SplitLayoutItem>Navigation</SplitLayoutItem>
      <SplitLayoutItem>Content</SplitLayoutItem>
    </SplitLayout>
  );
}
```
