# Button

Button renders a native button with loading and disabled states. It preserves
native button semantics and exposes its state to assistive technology.

## React usage

```tsx
import { Button } from '@/react/components/Button';

export function MyComponent() {
  return <Button>Save changes</Button>;
}
```
