# Accordion

Accordion renders related sections that users can expand independently. The
React renderer implements the shared `@pastweb/components-core/Accordion`
semantic and accessibility contract.

## React usage

```tsx
import { Accordion, AccordionPanel } from '@/react/components/Accordion';

export function MyComponent() {
  return (
    <Accordion ariaLabel='Account help'>
      <AccordionPanel title='Change my password'>
        <p>Use the account settings page to change your password.</p>
      </AccordionPanel>
      <AccordionPanel title='Enable two-factor authentication'>
        <p>Choose an authenticator app from the account security settings.</p>
      </AccordionPanel>
    </Accordion>
  );
}
```

Use `transitionDuration` on `Accordion` to set the default panel animation in
milliseconds. Set it on an individual `AccordionPanel` only when that panel
needs a different duration. The shared core contract owns the public props,
mediator state, IDs, CSS variables, keyboard behavior, and native-renderer
mapping.

## React adapter API

| Surface | React behavior |
|---|---|
| `Accordion` ref | Forwards to the root `div` that contains the complete accordion. |
| `AccordionPanel` ref | Forwards to the semantic `section` for that panel. |
| `children` | `Accordion` receives `AccordionPanel` children in document order. Each panel receives its expandable content as children. |
| `Template name="header"` | Replaces content inside a panel's native trigger button. The heading, button, IDs, ARIA relationships, and keyboard behavior remain renderer-owned. |
| Context | `Accordion` publishes the core Accordion context for its `AccordionPanel` descendants. Consumers normally compose with `AccordionPanel` rather than reading it directly. |

## Accessibility in React

- Each panel title is rendered inside a native button within the configured
  heading level.
- The trigger uses `aria-expanded` and `aria-controls`; content uses
  `aria-labelledby` to retain the relationship exposed by the core mediator.
- A closed panel is `inert` and hidden from the accessibility tree, so its
  interactive descendants cannot receive keyboard focus.
- The optional `landmark` prop adds `role="region"` to panel content. Use it
  only when the content needs a navigable landmark.
- Custom header content belongs inside `Template name="header"` and must still
  provide a meaningful trigger name. Do not render another button in that slot.
