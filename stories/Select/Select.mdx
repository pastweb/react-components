# Select

Select presents a labelled trigger and single-selection listbox for custom
option content. The preview target uses a Button.

## React usage

```tsx
import { Template } from '@pastweb/react';
import { Select, SelectItem } from '@/react/components/Select';

export function MyComponent() {
  return (
    <Select label='Country' placeholder='Choose a country'>
      <Template name='content'>Choose a country</Template>
      <Template name='options'>
        <SelectItem value='gb'>United Kingdom</SelectItem>
        <SelectItem value='fr'>France</SelectItem>
      </Template>
    </Select>
  );
}
```
