# Placeholder

Placeholder reserves space while content loads. It is decorative by default;
use one non-decorative instance when the loading state must be announced.

## React usage

```tsx
import { Placeholder } from '@/react/components/Placeholder';

export function MyComponent() {
  return <Placeholder className='is-block is-rounded' />;
}
```

## Configurations

### Skeleton layout

Combine decorative placeholders to represent an avatar, title, and content.

```tsx
import { Placeholder } from '@/react/components/Placeholder';

export function MyComponent() {
  return (
    <section aria-busy='true' aria-label='Loading profile'>
      <Placeholder className='is-circle' />
      <Placeholder className='is-pill' />
      <Placeholder className='is-block is-rounded' />
    </section>
  );
}
```

### Announced loading state

Use status semantics once rather than announcing every skeleton shape.

```tsx
import { Placeholder } from '@/react/components/Placeholder';

export function MyComponent() {
  return <Placeholder decorative={false} ariaLabel='Loading search results' />;
}
```
