# Panel

Panel groups related content in a bordered, optionally rounded article with a
semantic heading, close action, and footer.

## React usage

```tsx
import { Panel } from '@/react/components/Panel';

export function MyComponent() {
  return <Panel title='Account settings'>Update your profile details.</Panel>;
}
```
