# FileUploader

FileUploader opens the native file picker and can also accept dropped files. A
visible trigger remains available to keyboard and assistive-technology users.

## React usage

```tsx
import { FileUploader } from '@/react/components/FileUploader';

export function MyComponent() {
  return (
    <FileUploader accept='image/*' label='Profile image' onAddFile={(file) => upload(file)}>
      Choose image
    </FileUploader>
  );
}
```

## Configurations

### Multiple files and a dropzone

```tsx
import { FileUploader } from '@/react/components/FileUploader';

export function MyComponent() {
  return (
    <FileUploader
      accept='.pdf,.doc,.docx'
      dropzone
      label='Supporting documents'
      maxNumber={3}
      multiple
      onAddFile={(file) => upload(file)}
    >
      Choose documents or drop them here
    </FileUploader>
  );
}
```

### File limits

`maxNumber` limits stored files and `maxSize` rejects oversized files. Check the
file in `onAddFile` to show product-specific feedback for accepted or rejected
uploads.

```tsx
import { FileUploader, formatSize } from '@/react/components/FileUploader';

export function MyComponent() {
  return (
    <FileUploader
      label='Attachments'
      multiple
      maxNumber={5}
      maxSize={10 * 1024 * 1024}
      onAddFile={(file) => console.log(`${file.name}: ${formatSize(file.size)}`)}
    >
      Choose up to five files
    </FileUploader>
  );
}
```
