# Stepper

Stepper communicates progress through an ordered sequence of stages.

## React usage

```tsx
import { Stepper } from '@/react/components/Stepper';

export function MyComponent() {
  return (
    <Stepper
      steps={[
        { label: 'Account' },
        { label: 'Confirmation' },
        { label: 'Complete' },
      ]}
    />
  );
}
```
