# ToastController

ToastController presents a temporary, politely announced status message. Use a
Notification as its content when the toast needs a title and a visible close
action.

## Portal installation

ToastController is opened through `Portal`, so portal helpers must be installed
before a toast can open. Install them once for the application with
`PortalsProvider`, or install the same `installPortals(...)` installer on
`GlobalContext`. Portal entries mount in their own React root, so their entry
provider must install the same portal context too.

## React usage

```tsx
import { createEntry, Portal, PortalsProvider, usePortal } from '@pastweb/react';
import { Button } from '@/react/components/Button';
import { Notification } from '@/react/components/Notification';
import { ToastController, useToastContext } from '@/react/components/ToastController';

const anchorsIds = { toaster: 'app-toaster' };

function ToastContent() {
  const { close } = useToastContext();

  return (
    <Notification onClose={() => close()} title='Saved'>
      Your changes are now available.
    </Notification>
  );
}

function ToastLauncher() {
  const toast = usePortal();

  return (
    <>
      <Button onClick={() => toast.open()}>Save changes</Button>
      <Portal path='toaster' use={toast}>
        <ToastController ariaLabel='Saved'>
          <ToastContent />
        </ToastController>
      </Portal>
      <div id={anchorsIds.toaster} />
    </>
  );
}

function getEntry() {
  return createEntry({
    Providers: ({ children }) => (
      <PortalsProvider anchorsIds={anchorsIds} getEntry={getEntry}>
        {children}
      </PortalsProvider>
    ),
  });
}

export function MyComponent() {
  return (
    <PortalsProvider anchorsIds={anchorsIds} getEntry={getEntry}>
      <ToastLauncher />
    </PortalsProvider>
  );
}
```

The equivalent GlobalContext installation is:

```tsx
import { GlobalContext, installPortals } from '@pastweb/react';

<GlobalContext use={installPortals({ anchorsIds, getEntry })}>
  <MyComponent />
</GlobalContext>
```
