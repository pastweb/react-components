# DropDown

DropDown reveals short contextual content or a collection of actions from a
trigger. It exposes expanded, disabled, and ID relationship state to assistive
technology.

## React usage

```tsx
import { Template } from '@pastweb/react';
import { DropDown } from '@/react/components/DropDown';

export function MyComponent() {
  return (
    <DropDown ariaLabel='More actions'>
      <Template name='target'>More actions</Template>
      <Template name='content'>Additional actions appear here.</Template>
    </DropDown>
  );
}
```
