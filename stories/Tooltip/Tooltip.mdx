# Tooltip

Tooltip supplies a short, non-interactive description when a trigger is hovered
or focused. Keep essential instructions visible in the page instead.

## React usage

```tsx
import { Button } from '@/react/components/Button';
import { Tooltip } from '@/react/components/Tooltip';

export function MyComponent() {
  return (
    <Tooltip content='Saves your changes without leaving this page.'>
      <Button>Save changes</Button>
    </Tooltip>
  );
}
```

## Configurations

### Placement and delays

```tsx
import { Button } from '@/react/components/Button';
import { Tooltip } from '@/react/components/Tooltip';

export function MyComponent() {
  return (
    <Tooltip content='Available to administrators only.' placement='right-start' showDelay={500} hideDelay={150}>
      <Button>Delete account</Button>
    </Tooltip>
  );
}
```

### Text trigger

Plain text is wrapped in a focusable trigger, so it remains available to
keyboard users.

```tsx
import { Tooltip } from '@/react/components/Tooltip';

export function MyComponent() {
  return <Tooltip content='UTC time is used for exports.'>Export time</Tooltip>;
}
```
