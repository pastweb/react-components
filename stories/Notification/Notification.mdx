# Notification

Notification presents a short, politely announced message with optional title,
close action, and footer content.

## React usage

```tsx
import { Notification } from '@/react/components/Notification';

export function MyComponent() {
  return <Notification title='Saved'>Your changes are now available.</Notification>;
}
```
